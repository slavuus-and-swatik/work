# Универсальная Платформа Онлайн-Записи и Продаж Услуг

Полнофункциональный веб-сайт и панель управления для сферы услуг с интерактивной онлайн-записью, каталогом услуг, выбором времени, адаптивным дизайном и мощной административной панелью для настройки под любую нишу бизнеса.

Сайт спроектирован так, чтобы его можно было **в пару кликов адаптировать, масштабировать и продавать** клиентам в самых разных сферах.

---

## 🌟 Возможности платформы

### 1. Клиентская витрина
- **Каталог услуг с категориями и поиском:** работает быстро как с 4 услугами, так и с 20–50+ позициями.
- **Интерактивный виджет записи:** выбор мастера, выбор услуги, выбор даты и доступного временного слота с учётом буферного времени и загруженности.
- **Подтверждение записи:** автоматическое бронирование слота, защита от пересечения времени.
- **Адаптивный мобильный интерфейс:** идеальное отображение на смартфонах, планшетах и мониторах.

### 2. 10 готовых ниш бизнеса (переключение в 1 клик)
В панели администратора встроены полноценные пресеты:
1. **Барбершоп** (Мужские стрижки, борода, королевское бритьё) — тема Графит & Золото.
2. **Массаж & Спа** (Релакс, оздоровительный массаж, спа-программы) — тема Изумруд & Зелёный.
3. **Салон красоты** (Стрижки, окрашивание, маникюр, брови) — тема Амбер & Розовый.
4. **Автосервис & Детейлинг** (Шиномонтаж, ТО, полировка, химчистка) — тема Индиго & Синий.
5. **Частный мастер / Эксперт** (Индивидуальные консультации, приём) — тема Индиго & Синий.
6. **Фотостудия & Продакшн** (Аренда залов, циклорама, фотосессии) — тема Графит & Золото.
7. **Фитнес & Персональный тренер** (Тренировки, йога, стретчинг) — тема Океан & Бирюза.
8. **Клиника & Стоматология** (Консультации врачей, гигиена, осмотр) — тема Чистый светлый.
9. **Тату-студия & Пирсинг** (Сеансы тату, авторские эскизы) — тема Рубин & Бордо.
10. **Клининг & Уборка** (Уборка квартир, химчистка мебели, окна) — тема Неон & Фиолетовый.

При выборе ниши автоматически меняются:
- Название и слоган компании;
- Полный каталог услуг с ценами и длительностью;
- Обложка высокого разрешения (Unsplash);
- Цветовая палитра и акцентный цвет;
- Единицы вместимости (мастера, посты, залы, кресла);
- Контакты и график работы.

### 3. Настройка оттенков, цветов и фото
- 8 готовых премиальных тем оформления;
- Выбор любого произвольного **HEX-цвета** с помощью колорпикера или ввода кода (например, под фирменный стиль клиента);
- Выбор готовых фотографий из каталога или указание прямой ссылки на фото / загрузка своего изображения;
- Моментальный предпросмотр изменений.

### 4. Масштабирование каталога услуг (от 4 до 100+ услуг)
- Кнопка **«Клонировать»** — добавление похожих услуг за 5 секунд;
- **Пакетное добавление** услуг;
- Разделение по категориям с авто-фильтрами на сайте;
- Сортировка порядка (вверх / вниз);
- Включение / выключение услуг без удаления.

### 5. Панель управления (Админка)
- Адрес панели: `/admin` (прямой переход или незаметная ссылка в подвале сайта);
- Это панель владельца магазина: редактирование каталога, настроек и заказов;
- Внутренняя панель эксплуатации платформы находится отдельно по `/platform-admin` и не отображается покупателям;
- Управление записями клиентов (подтверждение, отмена, фильтр по датам);
- Ручное добавление клиентов в календарь;
- Настройка рабочего времени, интервалов слотов (15, 30, 45, 60 мин);
- **Экспорт конфигурации (JSON):** сохранение настроек клиента в файл;
- **Импорт конфигурации (JSON):** мгновенное развертывание сохранённого шаблона;
- **Выгрузка базы клиентов в Excel (CSV);**
- **Скачивание полного ZIP-архива проекта** прямо из интерфейса.

## 🚀 Быстрый старт на локальном компьютере

### Переменные окружения администратора

Перед запуском скопируйте `.env.example` в `.env.local`. Для входа владельца задайте `AUTH_SECRET` и `ADMIN_PASSWORD_HASH_B64`; для внутренней панели отдельно задайте `PLATFORM_AUTH_SECRET` и `PLATFORM_ADMIN_PASSWORD_HASH_B64` (base64 от bcrypt-хеша). Используйте разные пароли и секреты. Пароли состоят из 32 символов; в окружении хранится только хеш. После трёх неудачных попыток каждый вход блокируется на час.

Сейчас проект содержит одну демо-компанию, единый пароль панели владельца и временное хранилище в памяти процесса. `/platform-admin` показывает обзор таких компаний, но персональные учётные записи владельцев, создание компаний и постоянное хранилище ещё не реализованы. Не используйте текущие демо-данные как рабочую базу магазина.

### Требования:
- Node.js версии 18+ или 20+ (рекомендуется LTS 20 или 22)
- npm или bun или yarn

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
После запуска откройте в браузере:
- **Витрина сайта:** [http://localhost:3000](http://localhost:3000)
- **Панель управления:** [http://localhost:3000/admin](http://localhost:3000/admin)

### 3. Сборка для продакшена
```bash
npm run build
npm start
```

## 🌐 Инструкция по хостингу и деплою

### Вариант 1: Vercel (Самый простой, бесплатный)
1. Создайте репозиторий на [GitHub](https://github.com) и загрузите туда код проекта.
2. Зайдите на [vercel.com](https://vercel.com) и нажмите **Add New Project**.
3. Выберите ваш GitHub репозиторий.
4. Нажмите **Deploy**. Проект определит Next.js и развернется автоматически за 1 минуту!
5. В настройках проекта Vercel привяжите свой собственный домен (например, `mysite.ru` или `barbershop-vip.ru`).

### Вариант 2: VPS / Dedicated Server (Ubuntu, Debian)
1. Установите Node.js и PM2:
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
sudo npm install -g pm2
```

2. Скопируйте файлы проекта на сервер и соберите:
```bash
npm install
npm run build
```

3. Запустите через PM2 (с автозапуском при перезагрузке сервера):
```bash
pm2 start npm --name "booking-site" -- start
pm2 save
pm2 startup
```

4. Настройте Nginx как Reverse Proxy на порт 3000 и подключите SSL-сертификат Let's Encrypt (`certbot --nginx`).

## 📦 Как скачать исходники прямо сейчас

1. **В браузере:** откройте панель управления `/admin`, в правом верхнем углу или на вкладке «Обзор» нажмите кнопку **«Скачать исходники (.zip)»**.
2. **Прямая ссылка на файл:** `http://ваш-домен/project-source.zip`
3. **Через API эндпоинт:** `http://ваш-домен/api/download-source`

Архив содержит 100% всех исходных файлов без тяжелых папок `node_modules` и `.next`, готов к мгновенной распаковке и запуску через `npm install && npm run dev`.
