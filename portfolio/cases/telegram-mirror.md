# DialogSpyBot — зеркало сообщений Telegram

[← Все проекты](../README.md) · [Исходный репозиторий rollce](https://github.com/rollce/DialogSpyBot)

Открытый проект **rollce**, указанный по запросу владельца портфолио. Участие Андрея в разработке пока не подтверждено; проект не представлен как его собственная работа.

По README репозитория это Telegram Business-бот для архивации подключённой бизнес-переписки: сообщения, версии правок, события удаления и медиа. Веб-интерфейс показывает чаты и таймлайн. Есть уведомления об изменениях и настройка срока хранения фото.

**Стек:** Go, PostgreSQL, Docker Compose.

Для портфолио изучена публичная документация. Развёртывание и доступ к реальной переписке не выполнялись. Исходный код не копируется; ссылка ведёт в авторский репозиторий.
