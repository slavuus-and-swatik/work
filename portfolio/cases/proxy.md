# VEXORA Proxy

[← Все проекты](../README.md)

Telegram-сервис управления прокси-подписками. Основные сценарии — получение пробного доступа, покупка, баланс, продление, повторная выдача доступа, поддержка и административные команды.

Приложение разделено на обработчики, сервисы, репозитории, фоновые задания и внешние интеграции. SQLite хранит состояние на постоянном томе. При запуске восстанавливаются незавершённые операции оплаты, выдачи доступа и доставки событий.

**Стек:** Python 3.12, Telegram Bot API, SQLite, Railway.

В подключённом Railway подтверждено наличие успешного развёртывания. Это не проверка нового платежа или пользовательского сеанса прокси. Рабочие конфигурации, адреса узлов, токены, платёжные данные и база пользователей в портфолио не публикуются.
